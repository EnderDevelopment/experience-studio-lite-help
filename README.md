# Experience Studio Lite Help

Simplify help access in Experience Studio Lite with this intuitive script.

## Features

- Interactive help menu
- Tutorial and support access
- Help request logging

## Requirements

- FiveM server
- ESX Legacy framework
- MySQL database

## Installation

1. Download the script
2. Place the script in your FiveM resources folder
3. Add `start experience-studio-lite-help` to your server.cfg

## Usage

- Players can access the help menu by typing `/eslhelp` in chat
- The help menu provides options to access tutorials and support

## Configuration

The script can be configured in the `config.lua` file. You can customize the help menu title, subtitle, and options.
